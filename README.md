# Task-5 Exploring Data Analysis (EDA)

*Tool Used:* Python (Jupyter Notebook)  
*Dataset:* Titanic Passenger Data

## Objective
To perform a detailed exploratory data analysis (EDA) on the Titanic dataset, uncovering insights about survival trends, relationships between variables, and key observations.

## Key Features
- Data cleaning and preprocessing steps.
- *Boxplots* comparing Age vs. Survived.
- *Scatterplots* for Age and Fare comparison.
- *Heatmap* for correlation analysis.
- *Pairplot* for multivariate analysis.

## Observations
- Median age of survivors is slightly lower than that of non-survivors.
- Higher passenger class (Pclass) and fare have a positive correlation with survival.
- Outliers are observed in both age and fare distributions.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn
